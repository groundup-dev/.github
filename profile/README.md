# GroundUp

GroundUp is building open-source tools for the ground engineering industry to enhance collaboration, workflow automation, and data visualization.

## 🌍 Our Mission

We believe in empowering geotechnical engineers and geologists with modern, open-source tools that make data management and analysis more efficient and enjoyable. Our mission is to break free from siloed, fragmented datasets that hinder innovation in the ground engineering industry.

## 🏗️ Projects

### AGS Editor ([ags-validator](https://github.com/groundup-dev/ags-validator))
A free and open-source AGS file editor and validator. Try it at [validator.groundup.cloud](https://validator.groundup.cloud)

More projects coming soon! Stay tuned.

## 🤝 Contributing

We welcome contributions from the community! Here's how you can help:

1. **Report Issues**: Found a bug or have a feature request? Open an issue in the relevant repository.
2. **Submit Pull Requests**: Want to fix a bug or add a feature? Fork the repository, create a branch, and submit a PR.
3. **Provide Feedback**: Your feedback helps shape our roadmap. Share your thoughts through issues or discussions.

### Development Guidelines

- Follow the coding style and conventions used in each repository
- Write clear commit messages
- Add tests for new features
- Update documentation as needed
- Be respectful and constructive in discussions
